Niraj Choubey

I've spent more than a decade in application security. I started on the other side of the fence — writing and shipping software — which is probably why I still read code before I read reports.

These days I'm building multi-agent systems that do security work: agents that read, reason and report, so the humans can focus on the judgement calls.

LinkedIn ↗ Medium ↗ GitHub ↗

about

My path into security ran through development. Building features taught me how software actually gets made — under deadline, with shortcuts, with a half-finished understanding of someone else's module. That's the context I bring to every review and every threat model.

Today my work sits at the intersection of AppSec practice and automation. The interesting question for me isn't whether an agent can find a vulnerability — it's whether a set of agents can be trusted to triage, explain and prioritise one the way a good engineer would.

focus

  • appsec Secure code review, threat modelling, and SDLC practices that survive contact with real deadlines.
  • agentic ai Multi-agent architectures applied to security workflows — reasoning, tool use, and guardrails that hold.
  • automation Cutting the repetitive scanning and triage work so attention goes where it actually matters.
  • engineering A decade of writing software first — the habit of reading code closely never left.
